Première préversion pour Windows x64 et macOS (Apple Silicon). Elle n'a encore tourné sur aucun PC Windows ni sur aucun Mac : seuls les tests sans GPU passent, sur les machines de GitHub. Des choses vont casser, et vos retours aident.

Le lecteur est le même que sous Linux (voir la release linux-v0.1.0-preview.4) : agrandissement SPAN AnimeJaNai, interpolation RIFE ou DistilDRBA, sous-titres ASS et reprise de lecture.

## Windows (x64)

- `ajp-windows-x64.zip` : le lecteur et son moteur Vulkan, pour les GPU AMD, Intel et NVIDIA, avec les modèles SPAN AnimeJaNai HD V3.1, RIFE 4.25 et 4.22 lite, et DistilDRBA v2 Lite.
- **OpenVINO** (GPU Intel Arc et Xe, NPU des Core Ultra) se télécharge depuis l'écran de bienvenue. Il faut un pilote graphique Intel récent.
- TensorRT et RTX HDR ne sont pas encore proposés sous Windows : les cartes NVIDIA passent par le moteur Vulkan.

Installation : décompressez l'archive, puis, dans le dossier `ajp` :

```
ajp.exe play "épisode.mkv" --fullscreen
```

Il faut Windows 10 ou 11 en 64 bits et le pilote graphique à jour.

## macOS (Apple Silicon)

- `ajp-macos-arm64.zip` : AJP.app, avec le moteur Vulkan (MoltenVK) et Core ML, qui choisit pour chaque modèle entre le GPU et le Neural Engine. Les mêmes modèles que sous Windows sont inclus.
- L'application est signée sans certificat Apple : au premier lancement, macOS la bloque. Faites un clic droit sur AJP.app puis « Ouvrir », ou lancez `xattr -dr com.apple.quarantine AJP.app`.

Lancement depuis le Terminal :

```
AJP.app/Contents/MacOS/ajp play "épisode.mkv" --fullscreen
```

Il faut macOS 14 ou plus sur un Mac M1 ou plus récent.
