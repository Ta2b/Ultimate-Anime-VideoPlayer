Version 0.3, pour Linux x86-64, Windows x64 et macOS (Apple Silicon). Elle reprend la 0.2.x et ajoute le mode d'interpolation Auto, l'onglet Langues, GMFSS Performance / Qualité et le téléchargement direct de TensorRT. Le mode Auto, l'onglet Langues et la détection du VRR ont été essayés sur Linux (KDE Wayland, RTX 4070 Ti) pour la détection seulement ; la détection du VRR sous Windows n'a pas été essayée.

## Fichiers
- `ajp-linux-x64.tar.gz` : Linux, vérifiable avec `SHA256SUMS`.
- `ajp-windows-x64.zip` : Windows, vérifiable avec `SHA256SUMS-windows.txt`.

## Nouveautés
- **Interpolation en mode Auto** : le multiplicateur (×1 à ×6, soit 24 à 144 i/s pour du 23,976) suit ce que le GPU tient. Il baisse dès qu'une paire arrive en retard, remonte après quelques secondes sans retard, et retente de plus en plus tard un palier qui a échoué. Lecture seulement ; l'export garde un multiplicateur fixe. Le VRR de l'écran est détecté (DRM sous Linux, DXGI sous Windows) ; sans VRR, un avertissement le signale.
- **Onglet « Langues »** : audio et sous-titres choisis ensemble, avec deux préférences par ordre (par défaut : japonais + sous-titres français, puis français sans sous-titres). Nouvelle option « Aucun » pour les sous-titres. Les anciens réglages de `play.toml` sont convertis.
- **GMFSS Performance / Qualité** (base et union) : toujours en demi-flot ; Qualité passe GMFlow en FP32.
- **TensorRT en téléchargement direct** : le lecteur récupère de chez NVIDIA, par plages, seulement les fichiers dont ta carte a besoin (environ 739 Mo pour une RTX 4070 Ti au lieu d'une roue de 3,8 Go). Aucun fichier NVIDIA n'est redistribué dans nos versions.
