Version 0.2.0, pour Linux x86-64, Windows x64 et macOS (Apple Silicon). Elle reprend la preview.4 et ajoute la passe de corrections de l'audit. Elle n'a tourné que dans les tests automatiques (1180 tests sous Vulkan logiciel) : aucun GPU réel, ni les moteurs CUDA, HIP, OpenVINO, WinML et Core ML, n'ont été essayés avec ces changements.

## Fichiers
- `ajp-linux-x64.tar.gz` : Linux, vérifiable avec `SHA256SUMS`.
- `ajp-windows-x64.zip` : Windows, vérifiable avec `SHA256SUMS-windows.txt`.
- `ajp-macos-arm64.zip` : macOS, vérifiable avec `ajp-macos-arm64.zip.sha256`.
- `ajp-engine-…` : les moteurs que l'écran de bienvenue télécharge lui-même.

## Corrections
- **Export** : le fichier est écrit à part puis renommé à la fin ; un export refusé ou annulé ne détruit plus un fichier existant. Une erreur de lecture des pistes copiées est signalée.
- **Couleur et image** : la couleur de la source vient des paramètres du codec, les variantes proches sont approximées avec un avertissement, un HDR10 invalide est ignoré, et le rapport d'aspect des pixels est respecté, sous-titres ASS compris.
- **Pistes et sous-titres** : meilleur choix des sous-titres lisibles (dialogues complets, pas signs/songs/SDH) ; les entrées SRT ignorées sont journalisées.
- **Lecteur** : la pause est conservée à l'application des réglages, retour à l'accueil sur échec, reprise de position après une erreur de lecture.
- **Raccourcis** : Ctrl+G (grade), Ctrl+I (interpolation) et Ctrl+0 (source telle quelle) fonctionnent.
- **Modèles** : un lien symbolique qui sort du dossier du modèle est refusé ; correctifs dans l'IR, GMFSS, TensorRT, l'autotune Vulkan, MIGraphX, OpenVINO.
- libcurl n'est plus une dépendance.
